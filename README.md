# 그림일기 (Picture Diary)

일기를 쓰면 자동으로 아이 그림일기 같은 크레용 그림을 그려주는 앱입니다.

## 공개 웹 버전 (공유 가능)
공개된 웹 버전은 아래 주소에서 열 수 있습니다:

**https://rjs198426-lang.github.io/picture-diary/web/**

(구글 페이지가 활성화되면 사용 가능)

### Pages 활성화 방법
1. 리포 Settings → Pages
2. Source를 **Deploy from a branch**로 선택
3. Branch: `main`, Folder: `/web` (또는 `/`)
4. Save 후 1~2분 기다리면 위 주소로 열립니다.

## Android 빌드
GitHub Actions에서 APK를 빌드합니다. Actions 탭에서 Artifact를 다운로드하세요.
